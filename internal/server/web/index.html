👋 欢迎使用 StreamBridge

StreamBridge 可以把摄像头(RTSP/RTMP)的视频流在浏览器中直接播放。

无需安装任何插件,无需 Docker,单文件即可运行。

🚀 快速开始:

  1. 点击「▶ 播放示例流」体验效果(无需摄像头)
  2. 在输入框粘贴你的摄像头 RTSP 地址
  3. 不知道地址?点击「🏷️ 品牌」选择摄像头品牌获取模板
  4. 点击「播放」按钮即可

💡 小贴士:

  • 播放后可以点击「⭐ 收藏」保存地址
  • 点击「⊟ 分屏」可以同时查看多个摄像头
  • H265 摄像头建议使用 HLS 模式或开启转码
  • 遇到问题可以访问「诊断」页面排查
